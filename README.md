# Personal Portfolio

This is my personal portfolio website showcasing my background, skills, and the projects I am building as a Computer Engineering student aspiring to become a Full-Stack Developer.

**Live site:** https://devbea006.github.io/My-Portfolio/

## Pages

- Home
- About
- Projects
- Contact (with a working contact form)

## Built with

- HTML
- CSS
- Formspree
- Git and GitHub
- GitHub Pages

## What I learned

- How to structure web pages using HTML.
- How to style responsive layouts using CSS and media queries.
- How to use Git and GitHub to manage code and publish a website.
- How to fix a rejected git push by pulling and merging unrelated histories.

## Run it locally

Clone the repository:

```
git clone https://github.com/devbea006/My-Portfolio.git
```

Open the project folder:

```
cd My-Portfolio
```

Open `index.html` in your browser, or use the Live Server extension in VS Code.
